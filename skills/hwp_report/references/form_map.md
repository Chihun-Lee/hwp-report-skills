# 양식 구조와 엔진 동작 — (양식1) 전략연구사업 연구보고서_연차점검

양식은 `assets/forms/annual_review_2026/form.hwpx`(2026년 연구운영실 배포본 그대로)이고, 엔진이 찾는 제목 정규식은 같은 폴더 `profile.yaml`에 있다.

엔진은 문단 번호가 아니라 **제목 글자**로 위치를 찾는다. 그래서 다음 해 양식도 아래 제목이 같으면 그대로 쓸 수 있다.
양식이 바뀌면 `HR config add-form`으로 등록한다(`forms.md`). 제목 문구만 달라졌으면 그 양식 `profile.yaml`의 정규식을 고친다.

## 문서 순서

| 양식 부분 | 엔진이 찾는 글자 | 처리 |
|---|---|---|
| 표지 | 「과제명(국문)」「과제명(영문)」, 날짜 「2026. 11.」 | `cover.title_ko/title_en/date` |
| 제출문 | 「이 보고서를 “…”」, 「2026년 11월 13일」 | 따옴표 안을 「{과제명}에 관한 연구」로 바꾼다(누름틀 안내문 포함). 날짜는 `submit_date` |
| 참여연구원 표 4×3 | 제출문 날짜 뒤 첫 표 | `participants` |
| 요약표 39×29 | 그다음 표 | `summary`, `summary_sign`, `summary_fit_rows`. 확인란 날짜는 `submit_date` |
| 목차 | 「<  목 차  >」 | 탭·쪽번호와 [별첨자료] 줄을 지운다(`toc`) |
| 작성 안내 박스 | 목차와 1장 사이 표 | 지우고 1장 제목에 쪽 나눔을 건다(`guide_box`) |
| 1. 연구개발과제의 개요 | 마지막 「연구개발과제의 개요」 | 예시 「ｏ/-/‧ 세부설명」 → `overview` |
| 2. 수행과정 및 수행 내용 | 「2. 연구개발과제의 수행과정」 | 예시 → `work` |
| 진도점검 지적사항 표 | 「진도점검 지적사항」 | 제목을 ｏ 굵게 고치고 표 → `review`. 뒤의 빈 줄을 지우고 3장을 새 쪽에서 시작한다 |
| 3-1) 진척도 표 8×4 | 「1) 당해연도」 | `progress`(첫 열 병합 묶음으로 다시 짠다) |
| 3-2) 성과목표 달성도 표 9×9 | 「2) 기술적 성과목표」 | `targets.header/groups`. 표 아래 예시 → `target_notes` |
| 3-3) 세부 정량성과 | 「3) 세부 정량적」 | `outputs`에 적은 □ 항목만 남긴다. 빈 범주([과학적 성과] 등)와 안내문도 지운다 |
| 3-4) 계획하지 않은 성과 | 「4) 계획하지 않은」 | 「※ 해당하는 경우 …」 안내문 → `unplanned` |
| 3-5) 연구개발비 사용실적 | 「5) 연구개발비 사용실적」 | 그대로 둔다(책임자가 기관 회계시스템 캡처로 채움) |
| 4. 다음 연도 계획 1)~7) | 「4. 다음 연도」 아래 「N) …」 | 제목 뒤 첫 빈 줄 자리에 `next_year.N` |
| 5. 참고문헌·주의 | 「5. 참고문헌」 | 그대로 둔다 |

3·4장의 「N)」, 「[…]」, 「□」 제목에는 다음 문단과 함께 두기(keepWithNext)가 걸린다. 쪽 나눔이 이미 걸린 제목은 뺀다.
