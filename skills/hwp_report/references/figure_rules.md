# 보고서 그림 규칙 (요약)

자세한 패널 패턴과 작업 순서는 `report-figure` 스킬에 있다(같은 작성자의 짝 스킬).
이 스킬만 받은 사람도 아래 규칙으로 그림을 만들 수 있다. 스타일 파일은 `templates/figstyle.py`다.

## 원칙

1. **실데이터만 쓴다.** 재료는 다음 다섯 가지다.
   - 측정값 그래프
   - 원본 사진(현미경·장비·시편, 스케일바 포함)
   - 원본 문서·표를 잘라낸 것
   - 장비 로그에서 뽑은 궤적·시간
   - 시뮬레이션 렌더
2. **AI 생성 이미지·픽토그램·아이콘을 쓰지 않는다.**
   - 작성자가 직접 지정한 AI 렌더(예: 공정 라인 예상도)만 예외로 넣는다.
   - 그때는 캡션에 「(AI 생성 이미지)」를 붙이고, 그림 우하단에 「AI 생성」을 적는다.
3. **개념도는 도형으로 그린다.** 상자·선·화살표에 실제 파라미터 값을 적는다.
4. **수치는 다시 계산해서 검증한다.** 문서 값과 다르면 그림·본문을 고치고 작성자에게 알린다.
5. **근거 파일이 없는 수치는 그림에 넣지 않는다.** 작성자가 뺀 내용은 그림과 본문에서 함께 뺀다.
6. **아직 수행하지 않은 다음 연차 내용은 당해 연도 그림에 넣지 않는다.**

## 모양 (2026-11 두 최종본 기준 — 예전 판과 다르면 이 절이 우선)

- **배경은 흰색**이다. 회색 판·색 띠·발표 장 꾸밈을 깔지 않는다.
- **그림 안에 소제목·패널 글자(a·b·c)를 달지 않는다.** 사진 속 장비 이름처럼 대상을 가리키는 짧은 이름표만 둔다. 패널을 가리켜야 하면 캡션에서 「(a) …, (b) …」로 쓴다.
- **그림 안에 표·일정표를 넣지 않는다.** 표는 본문 표로 뺀다.
- **그림 안에 날짜를 넣지 않는다**(「2026.10.15 기준」 등).
- **한국어 보고서면 축·범례·이름표는 한글**로 쓴다. 원소 기호·시편 ID·단위·약어(OM, SEM, XRD …)는 그대로. 용어는 「영상」 대신 「이미지」.
- **그래프 모양**(작성자가 최종본 모양으로 정함 — 예전의 「옅은 눈금선·범례 아래」를 대신함):
  - 그림 영역에 테두리, **눈금선 없음**, 범례는 **그림 영역 안 빈 곳**
  - 핵심 수치(평균 절대오차, 시편 수, 대표 강도 등)를 그래프 안에 적는다
  - 문서 안 모든 그래프의 글자 크기·표식 크기·선 굵기·색 순서를 맞춘다
  - 글자는 문서에 들어간 크기로 10 pt 안팎(본문 11~12 pt 기준). 작으면 키운다
- **수정할 수 있는 PPT로** 달라고 하면 그림 1개 = 빈 슬라이드 1장으로 만든다. 그래프는 네이티브 차트, 도식은 도형, 사진·화면만 그림 개체다. 작성자가 PowerPoint에서 고쳐 다시 붙이므로 꾸밈 없이 깨끗하게.
- **폰트**: Arial + 나눔고딕 폴백. 어떤 글자도 7.5 pt 아래로 내리지 않는다. 한글에 mathtext(`$…$`)·`fontweight="bold"`를 쓰지 않는다.
- **주제별로 나눠** 관련 문단 바로 뒤에 둔다. ❍ 묶음 하나에 그림 하나가 기본이다.
  - 설계 폭은 140 mm 안팎(빽빽한 그림은 170 mm까지), 높이 120 mm 이하. 400 dpi.
  - 문서에는 1:1로 들어가고 상한은 150 × 105 mm다.
- **jpg로 저장**(dpi=96 메타)해서 spec의 `figures` 폴더에 둔다. 파일 이름이 곧 그림 ID다.

## 어디에 어떤 그림

- **수행 과정 장(2장)에는 방법 그림, 결과 장(3장)·요약 절에는 결과 그림.** 요약 절(정성적 성과)은 2장 그림을 다시 쓰지 않고 「입력 → 출력」, 「측정 흐름」 같은 요약 개념도를 새로 만든다. 같은 그림이 문서에 두 번 나오면 고친다.
- 각론 절(장비·AI 모델)은 주 내용 절에 없는 그림(설치 사진, 모델 구조도)을 쓴다.
- **여러 사진은 표 한 줄에 나란히** 두고 아래 행에 칸마다 짧은 설명을 단다. 장비 구축은 심의결과서·입찰공고·설치 사진으로, 교육은 현장 사진 + 참석자 서명록으로 증빙한다.
- **캡션 꼴과 위치는 문서 프로필**(`writing_rules.md` C1)을 따른다: 아래 `<…>`, 아래 `[…]`, 위 `‧ …` 줄, 또는 없음. 한 문서 안에서 섞지 않는다. 번호는 붙이지 않는다.
- **AI 생성 이미지**는 작성자가 지정했을 때만 넣고 그림 안 우하단 「AI 생성」 표시를 남긴다. 그림을 잘라 쓸 때 이 표시가 잘려 나가지 않게 한다. 실제 배치 렌더가 생기면 바꾼다.
