# 주관기관 통합 양식에 우리 기관 파트 넣기

공동연구 과제에서는 주관기관이 **자기 몫을 이미 채운 통합 양식**(hwpx)을 보내고, 공동기관은 비워 둔 자기 칸만 채운다.
이때는 `HR build`로 양식을 처음부터 채우지 않는다. **남의 글·표·그림·메모는 한 글자도 바꾸지 않고**, 우리 칸만 주관기관 서식으로 고친다.
실제 120쪽 넘는 5구역 통합 양식(본문·성과표·연구비·별첨)에 공동기관 파트를 넣고, 주관기관 1차 취합과 최종 제출까지 간 과정에서 정리했다.

## 0. 먼저 정할 것

- **바탕 파일 두 개**: 주관기관 양식(읽기 전용, 해시 기록) + 우리 기관 단독본(내용 원천, 다른 세션이 고치는 중이면 읽기만).
- **산출물 폴더**: `claude_iteration/vN_MMDD/`. 작성자가 한컴에서 고친 판은 `vN_MMDD_사용자수정/`에 두고 다음 판의 바탕으로 쓴다.
- **마감 두 개**를 적어 둔다: 주관기관 1차 취합일, 전문기관 최종 제출일.

## 1. 양식 읽기 — 어디가 우리 칸인가

```bash
HR dump 통합양식.hwpx -o 덤프/          # 구역별 문단(문단·글자 모양 번호)·표 칸·모양 뜻·메모
HR dump 통합양식.hwpx --find '공동연구개발기관|우리기관명'
HR dump 통합양식.hwpx --memos            # 주관기관 메모 = 작업 지시
```

1. **구역 대응표**를 만든다. 예: 통합 양식 구역 0 표지·요약 / 1 본문 / 2 공통 성과표 / 3 연구개발비 / 4 별첨 ↔ 단독본 구역.
2. **기관 표시 줄**(`[공동연구개발기관N (기관명)]`)로 우리 칸을 찾고, 칸마다 상태를 분류한다.

   | 상태 | 처리 |
   |---|---|
   | 빈칸·자리표시(빈 □, 「로봇」 같은 메모용 낱말) | 우리 내용으로 채움. 지우기 전에 글이 예상과 같은지 확인하고, 다르면 멈춤 |
   | **작년 우리 내용이 남은 칸** | 올해 내용으로 바꿈. 바꿨다고 작성자에게 알림 |
   | 기관 표시가 없는데 우리 담당인 절 | 메모·작년 판으로 확인 후 기관 표시 줄을 주관기관 번호 규칙대로 새로 넣음 |
   | 주관기관이 쓴 「(해당 없음 …)」 같은 글 | **그대로 둠**. 지우자고 판단되면 작성자에게 묻기 |
   | 사업 전체 합계 칸(「?/목표」, 총계) | 주관기관 몫. 메모가 「기관별로 ?에 기재」라고 한 칸만 채움 |
   | 공용 표(일정표·추진체계표) | 우리 행만 고침. **별도 표를 새로 만들지 않음** |

3. **주관기관 메모를 작업 지시 목록으로 옮긴다**(작성 범위, 「그대로 사용」, 「변동 없으면 유지」, 금액 단위 내림 규칙, 기관장 성함 확인, 직인 스캔 등).
   메모는 지우지 않는다. 우리 단독본에 작성자가 단 메모는 같은 자리로 옮긴다.

## 2. 서식 — 주관기관 서식으로 다시 만든다

- 단독본 문단을 그대로 붙이지 않는다. 글꼴·크기·글머리 체계가 다르면(예: 단독본 바탕체 12pt + 글자로 쓴 ❍, 통합본 돋움체 11pt + 자동 글머리) 한 문서 안에서 섞여 보인다.
- **주관기관 본문에서 단계별 본보기 문단을 하나씩 골라** 복제해 글만 바꾼다(`hwpx_patch.clone_para`).
  - □ 제목 / ❍ 항목 / - 세부 / · 근거 / 그림 문단 / 캡션 / 기관 표시 줄 — 각각 문단 모양(pp)·글자 모양(cp) 번호를 덤프에서 적어 둔다.
  - 새로 넣는 문단은 주관기관이 쓴 스타일(보통 「바탕글」)을 그대로 쓴다.
- 굵게·아래첨자(A_g 등)가 필요하면 본보기 글자 모양을 복제해 변형을 하나 더 만든다(`add_charpr_variant`).
- 표는 주관기관 표의 칸을 그대로 쓰고 글만 바꾼다. 행이 모자라면 같은 표의 행을 복제한다(세로 병합 보정 포함).

## 3. 넣을 때 깨지기 쉬운 것 (실제 사고)

| 증상 | 원인 | 지킬 것 |
|---|---|---|
| 메모 날짜가 「28140/11/28」로 나옴 | 메모 Command의 FILETIME 자리에 다른 값이 들어감 | 메모를 옮길 때 원래 메모의 Command·작성 시각을 그대로 가져온다 |
| 표 칸 합계가 0으로 나옴, 계산식이 사라짐 | 칸 글을 통째로 바꾸며 FORMULA 필드를 지움 | 칸 안 메모·계산식 필드를 보존하고 결과값(LastResult)만 갱신 |
| 복제한 행에 주관기관 메모가 따라옴 | 행 복제 때 메모 필드도 복제 | 복제 행의 메모 필드는 지운다 |
| 미리보기에서 그림이 엉뚱한 자리에 | 쓰지 않는 작년 그림을 패키지에서 지워 BinData 번호가 비었음 | **패키지의 그림 파일은 지우지 않는다.** 본문 참조만 뺀다(한컴은 이름으로 찾아 문제없지만 rhwp가 어긋남) |
| 사유 문장이 굵게 나옴 | 이웃 굵은 문단을 본보기로 복제 | 본보기 글자 모양을 확인하고 보통 굵기 cp로 지정 |
| 제목에 작년 연차가 남음 | 「(2차년도)」 같은 제목·표 머리는 주관기관 글이라 그대로 둠 | 우리 칸 제목·우리 표 머리의 연차는 올해 기준으로 고치고 알린다 |
| 인원·가동률 칸에 작년 값 | 단독본 값이 미확정 | 모르는 값은 `○○명`, `○○%` 자리표시로 두고 확인 목록에 올린다 |

## 4. 검증 (넘기기 전)

1. **보존 검사**: 주관기관 최상위 문단(지운 자리표시 제외)이 같은 순서·같은 글로 남았는지, 표 칸은 우리가 고친 칸 말고 모두 같은지, 메모·그림 개수가 맞는지 스크립트로 대조한다.
2. **누락 검사**: 단독본 우리 문단이 결과에 빠짐없이 들어갔는지(글머리 기호 차이는 정규화).
3. `HR check 결과.hwpx` → 구조 ERROR 0.
4. `HR pdf 결과.hwpx` → 한컴에서 손상 경고 없이 열리는지, 쪽 수, 우리 쪽 그림·표.
   - 100 MB·130쪽 문서는 PDF 저장에 몇 분 걸린다. 화면이 꺼져 있으면 못 뽑는다(종료 코드 3) — 「한컴 쪽 확인 대기」로 보고한다.
5. `HR tail 결과.pdf --hwpx 결과.hwpx --skip-form 통합양식.hwpx` → **우리 문단만** 꼬리 줄 점검.
6. 우리 칸 배치표(md)를 만든다: 양식 위치 → 넣은 내용 → 출처(단독본 위치) → 확인 필요.

## 5. 다음 판

- 단독본이 새로 바뀌면 같은 조립 스크립트로 다시 옮긴다. 스크립트는 **양식 문단 번호를 덤프와 대조**하고, 주관기관이 양식을 새로 보내 번호가 달라졌으면 멈춘다(우리 칸 번호를 다시 잡는다).
- 작성자가 한컴에서 고친 판이 오면 그 판을 바탕으로 **필요한 블록만 바꾸는 패치 스크립트**를 쓴다(예: 다음 연도 계획 블록 + 공용 일정표 우리 행). 통째로 다시 조립하지 않는다.
- `HR learn 이전판.hwpx 사용자수정본.hwpx -o 수정포인트.md`로 작성자가 무엇을 고쳤는지 읽고, 반복되는 것은 규칙으로 남긴다.
- 특정 쪽만 따로 달라고 하면(예: 일정표 한 쪽) 그 표만 담은 hwpx를 따로 만든다. 미리보기 글을 표 내용으로 채워야 검사 경고가 없다.

## 스크립트 뼈대

```python
import sys; sys.path.insert(0, "<스킬>/scripts")
from hwpx_patch import Package, HP, clone_para, ptext, tables, cell, set_cell, clone_row, strip_lineseg

pkg = Package("통합양식.hwpx")
sec = pkg.xml("Contents/section1.xml")                 # 본문 구역
ps = sec.findall(HP + "p")
slot = next(i for i, p in enumerate(ps) if ptext(p).strip() == "[공동연구개발기관1 (○○기관)]")
tpl_dash = ps[slot + 3]                                 # 덤프로 고른 「- 세부」 본보기 문단
new = clone_para(tpl_dash, runs=[(tpl_dash.find(HP + "run").get("charPrIDRef"), "- ○○ 자동화 측정 체계 구축")])
ps[slot].addnext(new)
strip_lineseg(sec)                                      # 고친 구역의 줄배치 캐시 제거(한컴이 다시 계산)
pkg.save("claude_iteration/v1_MMDD/결과.hwpx")
```

- 글머리가 자동 글머리(문단 모양에 heading)인 본보기를 복제할 때는 글 앞에 기호를 또 쓰지 않는다.
- 여러 칸을 채우는 일은 **칸 명세(json: 표 번호·행·열·값)** 로 따로 적고 실행기 하나로 돌린다. 명세를 병렬 에이전트가 만들어도 XML은 메인 한 곳에서만 고친다.
