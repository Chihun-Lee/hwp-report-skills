# 국책 R&D 보고서 장별 작성법

연차보고서·연차점검 보고서를 장·절 유형별로 어떻게 쓰는지 정리했다. 두 최종 제출본(단독 연차점검 양식, 주관기관 통합 양식)을 해부한 결과다.
문체·선별 규칙은 `writing_rules.md`, 통합 양식에 넣는 기술은 `consortium_merge.md`에 있다. 아래 예시 문장은 설명용으로 바꿔 쓴 것이다.

## 0. 쓰기 전에

1. **어떤 일인지 고른다.**
   | 경우 | 할 일 |
   |---|---|
   | 단독 양식을 처음부터 채움 | spec → `HR build` (SKILL.md 3~5절) |
   | 주관기관이 보낸 통합 양식에 우리 칸만 채움 | `consortium_merge.md` |
   | 수합본·통합본의 일부 블록만 고침 | 작성자 최신본에 패치(통째로 다시 만들지 않음) |
   | 제출 뒤 바뀐 내용을 보냄 | 「추가 파트 + 배치표」 또는 한 장짜리 「수정 내용」 문서 |
2. **근거를 모은다.** 계획서 진본(최종목표, 연차 목표, 세부기술 정식 명칭, 연구내용 문구, 성과지표, 다음 연도 계획의 쪽 번호), 작성 분담, 성과 원자료(측정값·로그·구매 상태), 지난 점검 지적사항 원문, 주관기관 메모.
3. **문서 프로필을 정한다**(`writing_rules.md` C절): 캡션 꼴·위치, 자동 글머리 여부, 약어 풀이, 종결(명사형/~함), 날짜·이정표 꼴, 과제 용어(spec `lint.replace`). 남의 글이 있으면 그 글에서 센다.
4. **분량 기준을 잡는다.** 같은 작성자의 확정 보고서나 같은 절의 주관기관 블록이 있으면 글자 수·그림 수를 재어 기준으로 삼는다.

## 1. 단계(글머리)의 역할

| 단계 | 역할 | 끝맺음 | 길이 |
|---|---|---|---|
| □ (또는 장·절 제목) | 과제 목표 1개 = □ 1개. 계획서 문구 | 명사구 | — |
| ❍ | 소제목: 세부기술 정식 명칭(단독 양식) 또는 「무엇을 했나」 명사구(통합 양식, 중앙 약 21자) | 명사구 (정성 성과 장은 결과 한 문장) | 15~30자 |
| - | 한 일 한 문장: 첫 - 는 목적, 가운데는 방법·결과, 마지막 - 는 의의 | ~함·~임·~됨·~할 수 있음 (또는 명사형) | 중앙 40~47자, 최대 90자 |
| ‧ / · | 근거·사양·정의·수치 한 줄 | 명사형 또는 ~임 | 짧게 |
| `*` 주석 | 용어 정의, 외주 사실 | 명사형 | 한 줄, 오른쪽 정렬(양식 관례일 때) |

- ❍ 묶음 하나에 그림 하나가 기본이다(그림은 묶음 끝). 그림 뒤에 의의 - 한 줄이 와도 된다.
- 단계를 건너뛰지 않는다(□ 바로 아래 ‧ 금지).

## 2. 수행 내용 (주 내용 절)

단독 양식에서는 「2. 수행과정 및 수행 내용」이 **과정**(어떻게 했나, 글 위주)이고 「3. 수행 결과」가 **결과**(무엇이 나왔나, 표·증빙 위주)다.
통합 양식에서는 「2장 1) 목표 및 수행 내용」이 **주 내용 자리**다. 우리 결과의 본문과 그림을 여기에 모으고, 2)~4) 각론 절은 요약 + 1)에 없는 그림으로 쓴다. 각론 절로 미루는 상호참조(「「4) AI 모델」에 기술함」)는 쓰지 않는다.

**틀**
```
□ 미세조직 측정·분석 자동화 시스템 구축              ← 과제 목표(계획서)
❍ 로봇팔과 현미경 연동 실험대 구성                    ← 명사구 소제목
- 작업자가 시편마다 개입하던 측정을 자동화하기 위해 장비 2종을 구축함     ← 목적
- 현미경, 로봇팔, 시편 홀더를 한 실험대에 배치하고 제어 PC로 연동함      ← 방법
  · 로봇팔은 6축 협동로봇, 현미경은 전동 스테이지 결합형임              ← 사양 한 줄
- 3D 프린터로 연속 시편 거치용 홀더를 자체 제작하여 로봇팔 작업 범위에 배치함
[그림]
[로봇팔과 현미경의 설치 모습]                         ← 문서 캡션 꼴
❍ 자동 분석 기공률의 정확도 검증
- 단면 이미지 100조건을 자동 분석하여 수동 측정값과 평균 절대오차 0.5%p로 일치함을 확인함
- 자동 분석 결과를 실험 DB에 바로 활용할 수 있는 수준임을 확인함           ← 의의
```
- 첫 □는 「목표 요약」으로 둘 수 있다: ❍ 「당해 연도 목표」 아래 계획서 목표 문장, ❍ 「당해 연도 수행 내용」 아래 결과 요약 4~5줄.
- 소제목 순서는 대체로 「데이터 → 방법 → 성능 평가 → 응용」.

**방법 항목(병목을 푼 일) 4줄**
```
- 분석 장비 자동화를 위한 용역 진행
‧ 단일 시편의 투입·감압·배출 과정이 오래 걸려 데이터 획득의 주된 병목으로 작용
‧ 이를 해결하기 위해 다중 시편 홀더를 설계하고 로봇팔로 홀더 투입·배출을 자동화하는 연구를 수행
‧ 장비 내부 구조와 제어 인터페이스를 가진 제조사와의 협업이 필수적이어서 자동화 도입 실적을 고려하여 수행 기관 선정
‧ 본 설계는 다음 연차 도입 장비의 기준 규격이 되며, 투입부터 데이터 저장까지 연속 수행으로 AI 학습 데이터 생성에 활용됨
```

## 3. 유형별 틀

### AI 모델 성과
`- 계획서 연구내용` → `‧ 목적` → `‧ 입력` → `‧ 출력·판정` → `‧ 기준값과 근거 규모` → `‧ 비교 우위 숫자` → `‧ 안정성` → 그림
- 「‧ 공정 전에 조성과 공정 조건만으로 결함 조건을 미리 걸러 내기 위한 결함 예측 모델을 개발」
- 「‧ 출력은 기공률 예측값과 예측 불확도이며, 이로부터 불량 확률을 계산하여 기준이 바뀌어도 재학습 없이 불량 판별이 가능」
- 「‧ 같은 데이터에서 A 모델(0.87)이 가장 높았고 B(0.82), C(0.76) 순임」
- 「‧ 5겹 교차검증을 반복하여 표준편차 ±0.02로 데이터 선별에 따라 큰 변화가 없음」
- 생성 모델은 「사전학습 모델은 고정하고 조건 인코더와 경량 어댑터만 학습하여 소규모 데이터로 이미지를 생성」처럼 핵심 아이디어 한 줄 + 지표(목표 대비) 한 줄.
- 통합 양식의 AI 각론 절은 ❍ 「모델 구조」/「평가 방법」 고정 라벨 + - 2~3줄 + 구조도(주 내용 절과 다른 그림).

### 소프트웨어 도구
`- 무엇을 만드는 도구 + 동작 환경 + 연계` → `‧ 기능 + 쓸모` ×2~3
- 「- 단면 이미지의 기공 정답셋을 만드는 웹 기반 라벨링 도구 개발, 로컬에서 동작하여 폐쇄망 PC에서도 사용 가능하며 모델 학습과 연계 가능」
- 「‧ 불확실한 기공부터 확대하는 검토 순서와 8종 클래스 지정 기능으로 불량 유형을 수동 분류 가능」
- 「- 원본 파일을 넣으면 표준 항목 지표와 조직 그림을 한 번에 산출함」 → 「- 프로그램은 연구자 PC 안에서만 실행되어 측정 데이터를 외부 서버에 올리지 않음」
- 각론(장비·SW) 절은 ❍ = 품목명, - = 한 줄 요약.

### 장비 구축
- 2장(과정): `- 장비 + 현재 상태` → `‧ 이정표`(문서 관례 꼴). 금액·심의 보완 경과·구매 규격 상세는 쓰지 않는다.
  - 「- 핵심 제조 장비 2종 도입 중」 / 「‧ `26.08 장비심의 도입인정. `26.10 입찰 진행 중」
- 3장(결과): `‧ 결과 한 줄(상태). 완료 예정 시기` + 증빙 사진 2열 표(심의결과서 | 입찰공고 | 설치 사진).
- 다음 연도 장비는 「설계」에서 멈추지 않고 「설계 및 제작·연동」까지 쓴다.
- 3천만 원 미만 소모성 장비는 성과로 올리지 않는다(양식 기준을 따른다).

### 실험 데이터 구축
- 첫 줄에 목적: 「물성의 일관성과 적층 방향별 차이를 확인하기 위해 인장 데이터를 구축함」.
- 시편 수·조건 수는 성과지표면 쓴다. 산출 근거가 곱으로 안 맞으면 근거 구절을 남긴다.
- 끝 줄에 연결: 「인장 물성은 공정조건 코드로 이미지와 연결되어 물성 예측 모델 학습에 쓰임」.
- 1차·2차 시험이 있으면 「2차는 실험 설계로 정한 조건을 포함한 N개 시편을 시험하여 예측 불확실성을 줄임」처럼 차수의 목적을 쓴다.

### 표준화
`❍ 표준 항목 제안` → `- 무엇을 몇 항목 정리해 어디에 제안, 반영됨` → `- 실제 데이터에 적용` + 촘촘한 본문 표(항목 | 단위 4쌍/행) + 캡션.

### 인력양성·교육
`□ 대상 + 교육 개최` → `❍ 대상 N명에게 교육 1건 개최함` → `- 일시·주제·강사` + [현장 사진과 서명록] 그림. 성과 표의 회수·시간·인원과 맞춘다.

### 정성적 성과 (3장 1))
- □ = 성과 이름, ❍ = **결과 한 문장**(명사구 아님), - = 근거 수치 2~4줄, 요약 개념도 1장(입력 → 출력, 측정 흐름).
- 2장 그림을 다시 쓰지 않는다. 같은 그림이 두 번 나오면 고친다.
- 주관기관 글이 「본 과제에서는 … 확보하였음」 총괄 문장으로 시작하면 우리도 ❍ 한 문장으로 총괄한다.

### 정량적 성과 표
- 성과목표 표 실적 칸은 숫자, 평가 전은 「-」. 해설 문단 없음.
- 사업 전체 표는 우리 칸만. 미확정은 `○○`.
- 논문·학회 표는 양식 꼴(날짜 YYMMDD 등)대로, 증빙은 별첨. 학회·교육은 회계 증빙(참가확인서·명찰 사진·수료증)과 같은 자료로 한 번에 모은다.
- 실적 인정이 불확실한 발표, 좌장·지도 같은 기타 활동은 책임자에게 묻고 올린다.

### 계획하지 않은 성과
- ❍ 한 줄씩, 실제로 적용한 방법만: 「❍ 2차 시험 조건을 실험 설계 기법으로 선정함」. 검토·조사·제안은 넣지 않는다. 없으면 「해당없음」.

### 목표 대비 기여 정도 (기술 현황 대비 위치)
양식의 고정 ❍ 라벨(「관련 분야 기술개발 현황 대비 본 연구성과의 위치」, 「우월성 및 기여한 점」)을 그대로 쓰고, - 에 「현황의 한계 → 우리 방법 → 지표」, · 에 「다른 소재·공정에도 적용할 수 있음」 의의.

### 진도점검 지적사항 및 반영사항
- 지적 칸: 원문 + 출처. 반영 칸: 지적 핵심어를 되받아 「~하고 ~ 완료」, 권장에 직접 대응한 조사·적용을 ‧로. 반영 줄마다 본문 근거 절.

### 진척도 표
- 행 머리·계획 칸 = 계획서 정식 문구. 실적 칸 = 「- 항목 (상태)」 줄. 본문과 같은 지표 이름(AUC를 정확도로 바꿔 쓰지 않음).

### 연구비
- 사용명세서 아래 미달 사유: 기준 충족 전망 2줄(`writing_rules.md` F7). 조회 기준 문구는 「※ 당해 연도 집행 조회 기준」처럼 날짜 없이.
- 금액 칸은 양식 메모의 단위 규칙(내림 등)을 따른다.

## 4. 다음 연도 계획

**목표 및 내용**
- 근거는 계획서의 다음 연도 쪽(연차 목표·성과지표·모델 정의·장비 목록). 쪽 번호를 작업 노트에 적는다.
- 첫 □(또는 ❍)에 확장 방향 한 줄 + 성과지표 숫자: 「- 추천 AI 모델과 시뮬레이터 2건 개발, 정확도 80% 이상」, 「- 장비 1건 구축, 가동률 70% 이상」.
- 다음 □부터 항목별로 ❍ 「무엇을」 → - 「어떻게」 → - 「평가 기준」 → - 「활용(다음 단계 연결)」.
  - 「❍ 목표 물성을 입력하면 이를 만족하는 미세조직과 공정조건을 제시하는 모델 개발」
  - 「- 생성 모델로 후보를 만들고 예측 모델로 평가하여 목표에 가장 가까운 후보를 찾음」
  - 「- 실험 전에 공정조건 후보를 좁혀 시편 제작과 시험 횟수를 줄일 수 있음」
- 계획 항목에도 효과 꼬리를 붙인다(「사전 검증 및 배치 변경 시 재학습 시간 감축」). 확정 전 수량은 쓰지 않는다.
- 계획 변경 세부(도입 시기 조정 등)는 본문에 드러내지 않는다. 한 구절(「장비 도입 계획 변경에 따라」)이면 충분하다.
- 단독 양식 수합본의 다음 연도 장 그림은 캡션 없이 넣는 관례였다.

**일정**
- **우리 담당 범위만**, 작성자가 정한 월 단위로. 남의 세부기술·기관 행을 만들지 않는다.
- 전 기관 공용 일정표가 있으면 **그 표의 우리 행만** 고친다. 별도 표를 만들지 않는다. 장비는 한 행에 묶고(「(일반) 시편 연마기 구축 및 로봇팔·현미경 연동」), 우리 몫이 아닌 분류는 쓰지 않는다. 표 머리 연차를 확인한다.
- 행 기간은 다음 연도 2~11월처럼 한 해를 고르게 덮게 나눈다.

**추진 방법·기대 성과**
- 추진 방법: 「~할 계획임」 한 줄씩(「구축 장비의 가동 시간을 관리 시스템에 기록하여 가동률을 관리할 계획임」).
- 기대 성과: - 묶음 이름은 「가능해지는 것」(「자체 제조 기반 데이터 확보 체계 구축」, 「고속 제조 라인 완성」), ‧ 에 근거·수치. 남의 세부기술 성과는 넣지 않는다.
- 책임자·주관기관이 사업 전체로 쓰는 절(환경변화·추진전략·활용방안·기대성과에 기관 표시가 없는 경우)에는 우리 블록을 끼워 넣지 않는다.

## 5. 넘길 때 알릴 것

- 산출물 경로(절대경로), 게이트·꼬리 줄·한컴 확인 결과(안 본 것은 안 봤다고).
- 추정해서 넣은 값, 남은 `○○` 자리표시와 위치, 확인이 필요한 사실(실적 귀속 중복, 지표 이름, 수치 불일치).
- 남의 글을 바꿨으면 그 목록. 주관기관 메모 중 아직 처리하지 않은 것.
- 같은 작성자의 이전 지시와 부딪히는 판단을 했으면 그 이유.
