# 보고서용 실데이터 figure 생성

보고서·발표 그림은 **실제 자료로 만든 논문식 다중 패널 figure**여야 한다. 실제 연차점검 보고서 작업에서 작성자가 정한 규칙을 코드화한 스킬이다.

- hwpx에 넣는 일은 짝 스킬 `hwp_report`가 한다. spec 본문에 `[그림 ID] 캡션` 줄로 넣는다.
- 공통 스타일은 이 스킬의 `templates/figstyle.py`를 프로젝트의 그림 폴더에 복사해 쓴다.
  - 들어 있는 것: Arial + 나눔고딕 폴백, 패널 라벨, 스케일바, 삼원계 좌표, 한글 볼드 제목, png·pdf·jpg 동시 저장

## 1. 원칙

1. **실데이터만 쓴다.** 다음 다섯 가지만 그림 재료가 된다.
   - 측정값 그래프
   - 원본 사진(장비·시료, 스케일바 포함)
   - 원본 문서·표 크롭(규격서·도면)
   - 장비 로그에서 뽑은 궤적·시간
   - 시뮬레이션 렌더
2. **AI 생성 이미지와 픽토그램·아이콘은 쓰지 않는다.**
   - 예외 ①: 작성자가 직접 지정한 AI 렌더(예: 설비 배치 예상도)는 넣는다. 이때 두 곳에 반드시 표기한다.
     - 그림 제목: 「…(AI 생성 이미지)」
     - 그림 우하단: 「AI 생성」
   - 예외 ②: 작성자가 「필요하면 AI로 그림 하나씩」을 허락한 경우에만 작은 삽화를 쓸 수 있다.
     - 배경은 흰색이나 투명으로 처리해 그림에 자연스럽게 섞는다.
     - 데이터처럼 보이게 라벨을 붙이지 않는다.
3. **개념도는 도형으로 그린다.** 알고리즘·절차·구성도는 matplotlib 상자·선·화살표로 그리고, 실제 파라미터 값을 적는다.
   - 개념도라는 사실은 제목에 「(개념도)」로 밝힌다.
4. **수치는 다시 계산해서 검증한다.**
   - 문서에 적힌 값과 재계산 값이 다르면 그림·본문을 고치고 작성자에게 알린다.
   - 예: 평균 편차를 낼 때 목표값이 0인 항목까지 넣으면 값이 작게 나온다.
5. **근거가 없으면 그리지 않는다.** 로그나 원자료가 없는 주장은 그림에서 빼고 「근거 없음」으로 보고한다.
6. **작성자가 뺀 것은 그림과 본문에서 함께 뺀다.** 그림 없이 본문 수치만 남기지 않는다. 반영표 같은 표의 수치까지 같이 정리한다.

## 2. 한글 표기 (보고서가 한국어일 때)

1. **한글로 쓰는 것**: 패널 제목·축 라벨·범례·표 머리·장비 라벨·절차 상자 문구. 자연스러운 보고서 명사구로 쓴다.
   - 예: 「목표 대비 실측 비교」, 「장비 소요시간」, 「합의된 시험 순서」
2. **그대로 두는 것**
   - 원소 기호, 시료 ID, 단위
   - 약어: OM, SEM, XRD, HV 등
   - 고유 표기: IP, 포트, OS, 소프트웨어 이름
3. **폰트**: `font.family = ["Arial", "Nanum Gothic"]`(templates/figstyle.py)로 한글만 나눔고딕으로 자동 대체한다.
4. **함정**
   - **한글이 든 라벨에 mathtext(`$...$`)를 섞지 않는다.** 한글이 □로 깨진다. 유니코드로 쓴다.
     - `ΔZ`, `√I`, `s cm⁻³`, `g/min`
   - **한글 제목에 `fontweight="bold"`를 쓰지 않는다.** 나눔고딕 굵은체를 못 찾아 영문만 굵게 섞인다. `btitle()`을 쓴다.
   - **한글과 섞인 아래첨자(N₂ 등)가 깨질 수 있다.** 이럴 때는 「질소」처럼 한글로 쓴다.
5. **날짜는 그림 안에 넣지 않는다.** PPT 합본만 예외로 우상단에 「기준일」을 적을 수 있다.

## 3. 크기·패널

1. **그림 안에 a·b·c 패널 글자를 쓰지 않는다.** 대신 소제목을 **볼드**로 단다.
   - 한글 볼드는 `btitle()`/`btext()`(templates/figstyle.py)를 쓴다.
   - 나눔고딕 ttc의 굵은체는 matplotlib이 못 읽으므로 KoPub돋움 Bold 같은 한글 볼드 폰트로 그린다.
   - 패널이 하나뿐인 그림은 볼드 제목을 넣지 않는다. 캡션과 같은 말이 두 번 나온다.
2. **그림 안 글씨를 크게.** 본문 9 pt, 패널 제목 9.5~10 pt, 표 셀 9 pt 이상으로 하고, 어떤 글자도 7.5 pt 아래로 내리지 않는다.
   - 원본 캡처에 박힌 작은 글자(컬러바 숫자, 작은 스케일바)는 잘라내고 matplotlib으로 다시 그린다.
3. **그림을 주제별로 나눠 글 사이사이에 넣는다.** 여러 주제를 한 그림에 몰지 말고, 관련 문단 바로 뒤에 작은 그림을 하나씩 둔다.
   - 설계 폭은 140 mm 안팎으로 한다(빽빽한 표는 170 mm까지). 높이는 120 mm 이하로 한다.
   - 400 dpi로 저장해 문서에 **1:1 물리 크기**로 넣는다. 그래서 그림 안 글자가 설계한 pt 그대로 나온다.
   - 문서 상한은 **150 × 105 mm**다. 큰 그림이 다음 쪽으로 밀려 쪽 아래에 빈칸이 크게 남으면 그림 크기나 문단 순서를 조정한다.
   - PPT용 합본은 원래 파일명으로 따로 저장한다.
4. **여백을 줄인다.** 패널 사이 빈 공간을 줄이고 `pad_inches=0.015`로 저장한다.
5. **캡션은 번호 없이 `<…>` 한 줄**, 가운데 정렬한다. 캡션 앞에는 4 pt 간격을 두고, 뒤에는 빈 줄 한 줄을 둔다. 이것은 `hwp_report`가 처리한다.

## 4. 워크플로우

1. **원자료 수집**
   - 파트가 여럿이면 탐색 에이전트를 파트별로 병렬로 돌린다.
   - 찾을 곳: 측정 엑셀·CSV, 장비 로그, 원본 이미지, 규격서 PDF, 발표 원본 미디어, 시뮬레이션 모델.
   - 쓴 원본은 `raw/<주제>/`에 복사한다. 원본 폴더에는 쓰지 않는다.
2. **그림 설계**: 패널마다 「무엇을 증명하는가」를 한 줄로 정한다. 그다음 아래 패턴에서 고른다.
3. **스크립트**
   - 그림 하나에 `fig_<주제>.py` 하나를 만든다.
   - `save()`로 png(400 dpi)·pdf·jpg를 함께 저장한다. 보고서 빌드는 jpg를 쓴다.
4. **검수**
   - 렌더 PNG를 직접 열어 확인한다.
   - 확인 항목: 제목끼리 겹침, 라벨과 점 겹침, 범례 가림, 잘린 표 글자.
   - 번호 상자가 몰리는 곳은 부분 확대(crop)까지 확인하며 고친다.
5. **문서 반영**
   - hwpx
     - **캡션은 한 줄로 짧게.** (a)(b)… 패널 나열을 쓰지 않는다.
     - **본문에서 그림을 괄호로 언급하지 않는다**(「(그림 2a)」 금지). 그림은 관련 문단 바로 뒤에 붙인다.
   - pptx
     - 그림 없는 슬라이드는 글을 전폭으로 배치한다.
6. **최종 검수**
   - 한컴 PDF로 쪽별로 확인한다.
   - hwpx 그림 함정은 `hwp_report` 스킬의 `references/layout.md`에 있다.
     - imgDim·imgClip = 픽셀 × 75
     - 그림 문단 줄간격 100%
     - BinData 이름 image1…

## 5. 검증된 패널 패턴

| 목적 | 패턴 |
|---|---|
| 목표 대비 실측 일치 | 패리티 플롯(1:1 선 + ±허용 띠, 평균 ● + 반복점 ○) + 편차 표(평균 [최소, 최대], 셀 색 = \|Δ\|) |
| 조성·조건 설계표 | 삼원계 삼각형 여러 개, 번호 상자 = 시료 번호, 채움 = 측정 완료. 4성분은 4번째 성분 함량별로 나눈 삼각형 + 색 범례 |
| 연차 확장 계획 | 연차 상자 + 화살표, 항목 칩(기존 회색, 신규 강조), 목표 건수 |
| 진행 현황 | 시료 × 항목 매트릭스(획득·진행·대기 3색, 그룹 머리, 오른쪽에 개수 열) |
| 합의된 절차 | 절단 도식(치수 표기) + 측정 위치 도식(점 개수 실제값) + 번호 단계 상자(자체·외주 색 구분) |
| 시뮬–실기 연동 | 같은 자세의 실기 프레임 ↔ 시뮬레이션 렌더 2×2 + 같은 경로 파일의 궤적 |
| 알고리즘 | 실측 궤적(로그) + 개념도(실제 파라미터) + 결과 영상 + 실측 성능 표 |
| 공간·시설 | 평면도에서 대상 실을 칠하고 점선 확대로 배치안 연결 |
| 네트워크·서버 | 상자 + 선 구성도(실제 IP·포트·OS, 예정 장비는 점선) |

## 6. 하지 말 것

- 생성 이미지로 「개념 일러스트」를 만들어 데이터 그림처럼 넣지 않는다.
- 작성자가 빼라고 한 사진을 다른 그림에 다시 넣지 않는다.
- 근거 파일이 없는 수치(성공률, 통과 수 등)를 표나 패널에 넣지 않는다.
- 같은 데이터를 두 그림에 중복해 넣지 않는다. 옮기면 원래 그림에서 패널을 지운다.
- 아직 수행하지 않은 다음 연차 내용을 당해 연도 결과 그림에 넣지 않는다. 계획서에 있는 연차 계획만 계획으로 표시한다.
- 상신·외부 발송·레포 푸시는 하지 않는다. 그림과 초안 파일까지만 만든다.
